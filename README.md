# NJT Copy

NJT-jogszabályok teljes szövegének másolása Wordbe illeszthető formázással és egyszerű szövegként. A kijelölést és a jobb kattintást is engedélyezi.

A jogszabály megnyitásakor a teljes szöveget automatikusan, görgetés nélkül betölti, így a böngésző keresője (Ctrl+F) az egész szövegben keres.

**[Telepítés Tampermonkey-ba](https://raw.githubusercontent.com/danzig666/njt-copy/main/njt-copy-jogszabaly.user.js)** — telepített [Tampermonkey](https://www.tampermonkey.net/) szükséges.

Telepítés után nyiss meg egy jogszabályt az [NJT-ben](https://njt.jog.gov.hu/), majd kattints a jobb alsó „Másolás Word-be” gombra.
